안정된 pn 접합 다이오드에서, 움직이는 캐리어 전하를 없다고 가정하면, 전압과 전하밀도는 다음과 같은 관계를 갖는다.
$$\frac{d^2V}{dx^2} = -\frac{\rho}{\epsilon} $$
이를 적분하면
$$\frac{dV}{dx} = -\frac{\rho}{\epsilon}x + C_1 $$
다시 한번 적분하면
$$V=-\frac{\rho}{2\epsilon}x^2 + C_1x + C_2$$
로, $y=ax^2+bx+c$ 의 꼴인 포물선의 형태가 나타나게 된다.

또한, 접합면을 0으로 놓고 공핍층의 영역을 $[x_D,x_A]$ 로 놓는다면, $E(x_D)=E(x_A)=0$ 이 된다.
$E(x)= -\frac{dV}{dx}= \frac{\rho}{\epsilon}x -C_1 =0$ 이므로 $C_1=\frac{\rho}{\epsilon}x$ 가 되며, 이를 이용해 V를 다시 정리하면,
$$V= \frac{\rho}{2\epsilon}(x-x_i)^2 \ \ \ \ \ (i=D \ or \ A)$$

---
이때, $\rho=qN$ 이며, p쪽에서와 n쪽에서의 $\rho$는 다음과 같이 나타난다.
$$\rho = \begin{cases} +qN_D \ \ \ \text{(n형 반도체)} \\ -qN_A \ \ \ \text{(p형 반도체)}\end{cases}$$
그런데, p형 반도체와 n형 반도체의 도핑 농도(N)가 다르면 접합면을 기준으로 양 쪽의 전하 밀도($\rho$)가 달라지게 되고, 이에 따라 p,n형 반도체의 전압 관계식은 서로 다른 포물선으로 나타나게 된다. x=0일 때 두 식의 값이 같아야 하므로 이를 반영하여 $V_A$ 의 상수항을 맞춰주면 아래와 같이 정리된다.

$$\begin{cases} V_D = -\frac{+qN_D}{2\epsilon}(x-x_D)^2 \\ V_A = -\frac{-qN_A}{2\epsilon}(x-x_A)^2 + \frac{q}{2\epsilon}(N_D x_D^2 - N_A x_A^2)\end{cases}$$

만약 n형 반도체의 도핑 농도가 더 높다면 $N_D>N_A$ 가 되므로, n형 반도체의 전압이 더 가파르게 변화한다.
그런데, $N_D x_D^2 = N_A x_A^2$ 이므로 $|x_D|<|x_A|$ 가 되어 p형 반도체의 공핍층 길이가 더 길어지게 된다.
