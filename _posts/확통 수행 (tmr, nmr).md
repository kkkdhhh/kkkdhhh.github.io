# 탐구 제목

**조합과 독립시행을 이용한 TMR·NMR 회로의 신뢰도 분석**

# 1. 탐구 동기

전자공학 시스템에서는 한 모듈의 오류가 전체 시스템 오류로 이어질 수 있다. 이를 보완하기 위해 동일한 모듈을 여러 개 배치하고, 다수결로 최종 출력을 결정하는 중복 설계가 사용된다. 이 구조는 확통의 **조합, 독립시행, 이항분포**로 분석할 수 있다.

# 2. TMR의 원리

**TMR**은 **Triple Modular Redundancy**의 약자로, 같은 기능을 하는 모듈 3개를 사용해 신뢰도를 높이는 구조이다.

- 모듈 3개가 같은 입력을 받는다.
- 각 모듈이 독립적으로 출력을 낸다.
- 3개 중 2개 이상이 같은 출력을 내면 그 값을 최종 출력으로 선택한다.

모듈 출력을 라 하면 majority voter의 논리식은 다음과 같다.

```latex

Y=AB+AC+BC
```

# 3. TMR의 기본 신뢰 확률

각 모듈이 정상 작동할 확률을 라고 하자.  
TMR이 정상 작동하려면 3개 중 2개 이상이 정상이어야 한다.

```latex

P_{\text{TMR}}
=
\binom{3}{2}p^2(1-p)
+
\binom{3}{3}p^3
```

```latex

P_{\text{TMR}}
=
3p^2(1-p)+p^3
```

```latex

P_{\text{TMR}}
=
3p^2-2p^3
```

예를 들어 라면,

```latex

P_{\text{TMR}}
=
3(0.9)^2-2(0.9)^3
=
0.972
```

단일 모듈의 신뢰도 보다 높다.

# 4. NMR의 원리

**NMR**은 **N-Modular Redundancy**의 약자로, TMR을 일반화한 구조이다.

같은 기능을 하는 모듈을 개 사용하고, 과반수 이상의 모듈이 정상 출력하면 전체 시스템이 정상이라고 본다.

보통 은 홀수로 둔다.

```latex

N=2m+1
```

이때 정상 작동에 필요한 최소 모듈 수는

```latex

m+1
```

이다.

예를 들어,

- : 3개 중 2개 이상 정상
- : 5개 중 3개 이상 정상
- : 7개 중 4개 이상 정상

# 5. NMR의 신뢰 확률

각 모듈의 정상 작동 확률을 라고 하자.  
개 중 정확히 개가 정상 작동할 확률은

```latex

P(X=k)
=
\binom{N}{k}p^k(1-p)^{N-k}
```

이다.

따라서 이 홀수일 때 NMR의 신뢰도는

```latex

P_{\text{NMR}}
=
\sum_{k=\frac{N+1}{2}}^{N}
\binom{N}{k}p^k(1-p)^{N-k}
```

이다.

예를 들어 5MR의 신뢰도는

```latex

P_{\text{5MR}}
=
\binom{5}{3}p^3(1-p)^2
+
\binom{5}{4}p^4(1-p)
+
\binom{5}{5}p^5
```

```latex

P_{\text{5MR}}
=
10p^3(1-p)^2+5p^4(1-p)+p^5
```

# 6. NMR이 단일 모듈보다 좋은 조건

단일 모듈의 신뢰도는

```latex

P_{\text{single}}=p
```

이다.

NMR이 단일 모듈보다 유리하려면

```latex

P_{\text{NMR}}>p
```

이어야 한다.

TMR의 경우,

```latex

3p^2-2p^3>p
```

```latex

p(2p-1)(1-p)>0
```

에서

```latex

p>\frac{1}{2}
```

일 때 성립한다.

따라서 TMR은 각 모듈의 신뢰도가 보다 클 때 단일 모듈보다 유리하다. NMR도 같은 원리로, 각 모듈의 신뢰도가 보다 클 때 다수결 구조가 효과적이다.

# 7. 결론

TMR과 NMR은 동일한 모듈을 여러 개 사용하고 다수결로 출력을 결정하여 시스템 신뢰도를 높이는 구조이다. 이때 신뢰도는 조합과 이항분포를 이용해 계산할 수 있다.

```latex

P_{\text{TMR}}=3p^2-2p^3
```

```latex

P_{\text{NMR}}
=
\sum_{k=\frac{N+1}{2}}^{N}
\binom{N}{k}p^k(1-p)^{N-k}
```

단, 이러한 중복 설계는 각 모듈의 신뢰도가 보다 클 때 효과적이다.
